## 👋 Hi, I'm Milan

### ⭐ **My favourite Projects**

**🎮 Rainbow DQN vs PPO on Games**  
  To learn reinforcement learning, I implemented 2 RL algorithms Rainbow DQN and PPO to play Flappy Bird and, one of my favorite games, Super Mario Bros. on the NES. This was one of the most fun projects I've ever did. Feel free to look into the [project](https://github.com/milannal1m/rainbow-vs-ppo)! (It has awesome videos of the agents playing too) 

**♟️ N-Queens-Solver in Racket**  
  So this project has a special place in my heart, because it was one of the first hard problems I solved in my very first semester of studying compsci. And tbh I have no idea how I solved it, back when ChatGPT couldn't help with stuff like this. This [Project](https://github.com/milannal1m/Racket-N-Queens-Solver) solves the [N-Queens Problem](https://en.wikipedia.org/wiki/Eight_queens_puzzle) for n's up to 32.

**🐉 EvoTrainer**  
  Developed [EvoTrainer](https://github.com/milannal1m/EvoTrainer), a Pokémon battle agent, for the [VGC AI Competition 2025](https://gitlab.com/DracoStriker/pokemon-vgc-engine) using evolutionary algorithms to improve battle behavior through generational evolution. And miserably failed ;).

**🍏 MealPlanner**  
  Developed [MealPlanner](https://github.com/milannal1m/MealPlanner), an iOS app designed to simplify meal planning. Worked on adding synchronization features ([Proof of Concept](https://github.com/milannal1m/MealPlannerSync)) between users and devices using Docker. But I sadly stop pursuing this project, as there are a gazillion apps like this now.

**📸 EOLVision**
